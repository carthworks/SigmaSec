Enterprise Grade Architecture

Your code stays in your environment.

Engineered for security-conscious teams who cannot transmit source code to multi-tenant third-party clouds.

Self-Hosted Isolation

Deploy the entire platform inside your own VPC using Docker Compose. Workers execute scanners locally and retain findings within your private PostgreSQL database.

Local Ollama AI Support

No external LLM required. Run vulnerability explanations and plain-English risk assessments entirely on-premises using local Ollama models with zero outbound calls.

Fernet Encryption & Auth

All integration tokens (GitHub, Jira, Slack) are encrypted with symmetric Fernet keys (ENCRYPTION_KEY). Scans against web endpoints require verified DNS or HTTP tokens.

Defensible Trust Framework

Claims backed by code, not marketing.

We adhere to strict transparency: our public statements reflect what the open source software actually enforces.

Security Question SigmaSec Implementation Status
Do you train on customer data? Never. Data is never used for training. Deploy with local Ollama for zero data egress, or use Claude under standard commercial terms. Guaranteed
Where is source code processed? Scanners and reachability checks run on your designated workers. Source repositories are cloned temporarily into ephemeral worker volumes and purged immediately. Ephemeral
How are integration secrets protected? Stored GitHub PATs, Jira API keys, and Slack webhooks are encrypted at rest using AES-128-CBC + HMAC (Fernet). The server refuses to start in production without a secret key. Encrypted
Can users scan unauthorized third parties? No. Web and network scans strictly enforce proof of ownership via DNS TXT record or HTTP challenge file. Loopback and internal private IPs are blocked. Enforced
What about DPDP Act 2023 & regional hosting? Self-hosted instances deploy into any regional datacenter (e.g. AWS Mumbai, GCP Delhi). Hosted instances offer dedicated geographic isolation on request. Self-Host
